# Jenkins

Installs Jenkins from the official `pkg.jenkins.io` package repository (APT/YUM/zypper),
LTS channel by default.

## Supported platforms

| OS family | Versions | Notes |
|---|---|---|
| Debian | Debian 11+, Ubuntu 20.04+ | `pkg.jenkins.io` Debian-format repo (deb822) |
| RedHat | RHEL/Rocky/Alma 8+, Fedora, Amazon Linux 2023 | `pkg.jenkins.io` rpm-format repo |
| Suse | openSUSE Leap 15+, SLES 15 | same rpm-format repo, added via `zypper` |

Upstream's platform support policy commits at the packaging-format level only (no
distro-version table); anything outside `ansible_os_family in ['Debian', 'RedHat', 'Suse']`
fails in preflight.

## Requirements

- Ansible core >= 2.15 (`deb822_repository`, `systemd_service`)
- Collections: `community.general` (`ansible-galaxy collection install -r requirements.yml`, SUSE only)
- Java 21 (installed automatically; Java 17 is no longer supported by current Jenkins releases)
- `sudo` on the target

## Usage

```bash
ansible-playbook install_jenkins.yml
ansible-playbook install_jenkins.yml --check --diff        # dry-run
ansible-playbook uninstall_jenkins.yml
ansible-playbook uninstall_jenkins.yml -e jenkins_purge_data=true   # also wipe JENKINS_HOME
```

## Variables

| Variable | Default | Description |
|---|---|---|
| `jenkins_channel` | `stable` | `stable` (LTS) or `weekly` |
| `jenkins_gpg_key_filename` | `jenkins.io-2026.key` | Repo signing key file; bump on the next upstream rotation |
| `jenkins_home` | `/var/lib/jenkins` | `JENKINS_HOME`, rendered into the systemd override |
| `jenkins_http_port` | `8080` | Set via systemd drop-in, not `/etc/default/jenkins` |
| `jenkins_java_opts` | `""` | Extra `JAVA_OPTS`, e.g. `-Xmx2g` |
| `jenkins_purge_data` | `false` | `uninstall_jenkins.yml` only — deletes `JENKINS_HOME` |

## Verify

```bash
systemctl status jenkins
curl -sI http://<host>:8080/login
cat /var/lib/jenkins/secrets/initialAdminPassword   # first-run setup wizard
```

## Notes

- **Repo signing key rotates.** The key used to sign `pkg.jenkins.io` packages is
  rotated periodically (the previous `jenkins.io-2023.key` expired 2026-03-26). If APT
  or DNF start rejecting the repository signature, check the Jenkins blog
  (jenkins.io/blog) for the current key filename and update `jenkins_gpg_key_filename`.
- **No `/etc/default/jenkins` / `/etc/sysconfig/jenkins`.** Since Jenkins 2.335 /
  2.332.1 the packages are systemd-managed; `JENKINS_PORT`, `JENKINS_HOME` and
  `JAVA_OPTS` are set through `/etc/systemd/system/jenkins.service.d/override.conf`,
  rendered by this playbook.
- The initial admin password is generated by Jenkins itself on first boot at
  `{{ jenkins_home }}/secrets/initialAdminPassword` — it is not a variable in this
  repository and is never logged.
- `jenkins_purge_data=true` deletes every job, credential and configuration. There is
  no confirmation prompt — review before running against production.
