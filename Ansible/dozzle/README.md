# Dozzle

Real-time Docker log viewer. Runs a server with the web UI, plus one agent per
remote Docker host. Docker must already be installed (see [../docker/](../docker/)).

## Supported platforms

| Requirement | Supported |
| --- | --- |
| Host OS | Any Linux that runs Docker |
| Docker Engine | >= 19.03 (API 1.40) |
| Architecture | x86_64, arm64 |

## Requirements

- Ansible core >= 2.15
- `ansible-galaxy collection install -r requirements.yml` (`community.docker`)
- `docker` python SDK on the target: `pip install docker`
- An admin password in Ansible Vault as `vault_dozzle_admin_password` when
  `dozzle_auth_provider` is `simple`

## Usage

```bash
ansible-playbook install.yml --ask-vault-pass
ansible-playbook uninstall.yml
ansible-playbook uninstall.yml -e dozzle_purge_data=true   # also delete /var/lib/dozzle
```

`install.yml` runs the agents first, then the server, whose `DOZZLE_REMOTE_AGENT`
list is built from the `dozzle_agents` inventory group.

## Variables

| Variable | Default | Description |
| --- | --- | --- |
| `dozzle_version` | `v10.6.13` | Image tag. Do not use `latest` |
| `dozzle_registry` | `amir20/dozzle` | Use `ghcr.io/amir20/dozzle` where Docker Hub is blocked |
| `dozzle_port` | `8080` | Host port for the UI |
| `dozzle_bind_address` | `0.0.0.0` | Set to `127.0.0.1` to keep the UI private |
| `dozzle_agent_port` | `7007` | Agent listen port |
| `dozzle_agent_publish` | `true` | Set false when server and agents share a Docker network |
| `dozzle_auth_provider` | `simple` | `none`, `simple` or `forward-proxy` |
| `dozzle_data_path` | `/var/lib/dozzle` | Bind-mounted at `/data` |
| `dozzle_enable_actions` | `false` | Allow start/stop/restart from the UI |
| `dozzle_enable_shell` | `false` | Allow container shell access from the UI |

## Verify

```bash
docker ps --filter name=dozzle
curl -sI http://<server>:8080
```

## Notes

- **The `/data` mount is required.** Without it the users file and every
  notification setting are lost each time the container is recreated.
- The users file is generated by running the image's `generate` subcommand once.
  The password is fed on **stdin**, not argv, so it never appears in the process
  table, and the result is written `0600` root-owned.
- **Actions and shell access are off by default and deliberately left off.** Both give
  UI users control over containers on the host.
- Mounting the Docker socket grants the container root-equivalent access to the host.
  Do not expose the UI publicly without authentication — Docker publishes ports past
  ufw and firewalld, so `dozzle_bind_address` is the effective control.
- **In Docker Swarm do not deploy agents.** Use `DOZZLE_MODE=swarm` with
  `deploy: mode: global` instead; the server self-discovers the cluster.
- `cleanup.yml`, `dozzle_cleanup.yml` and `dozzle_setup.yml` were folded into
  `install.yml` and `uninstall.yml`.
